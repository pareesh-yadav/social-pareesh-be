# Social Media Chat API

A robust real-time chat API built with Node.js, Express, PostgreSQL, and Socket.io.

## Features

- ✅ User Authentication (JWT)
- ✅ One-to-One Real-time Messaging
- ✅ Friend System with Requests
- ✅ User Search
- ✅ Message Edit & Delete
- ✅ Message Replies
- ✅ Typing Indicators
- ✅ Read Receipts
- ✅ Online Status Tracking
- ✅ Error Handling & Validation

## Tech Stack

- **Runtime**: Node.js
- **Framework**: Express.js
- **Database**: PostgreSQL
- **ORM**: Prisma
- **Real-time**: Socket.io
- **Authentication**: JWT
- **Language**: TypeScript
- **Validation**: Zod

## Prerequisites

- Node.js 18+
- PostgreSQL 12+
- npm or yarn
